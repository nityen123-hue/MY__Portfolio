
# ✣ Nityen Kakadiya — React Portfolio

A modern, responsive personal portfolio website built with **React.js**.

This portfolio showcases my profile, Full Stack Web Development learning journey, projects, resume and social links.

---

## 🚀 About The Project

This project is a personal portfolio website created to present my skills, projects and web development journey in a clean and responsive design.

The website includes:

- Personal introduction
- Profile section
- Full Stack Web Developer information
- Work section
- Bio / education timeline
- Projects showcase
- Resume page
- GitHub, LinkedIn and Instagram links
- Dark / Light mode
- Responsive design for mobile, tablet and desktop
